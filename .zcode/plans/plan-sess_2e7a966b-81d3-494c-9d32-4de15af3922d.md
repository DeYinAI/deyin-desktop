## Phase 3 — Chat UX overhaul (dsh patterns, zero-regression)
In `ChatView.tsx` + `useAgentState.ts`, keeping the existing `ThreadEvent` model:
- **ToolCard v2** (dsh "single-row fields inline"): one collapsed row = status icon + tool name + inline primary arg (path/command/query) + duration; expand for full args/result; running bash streams live; denied badge; consecutive read-tier tools group into an "N lookups" quiet chip.
- **Thinking rows**: streaming "Thinking… Ns" with timer → collapses to "Thought for Ns" disclosure row (dsh thinking-row-disclosure).
- **Subagents (dsh subagent-observe-enrich)**: enrich `subagent-start/end` payloads in `host-core/types.ts` (`id`, name, model, prompt, ok, duration, summary) and add `subagent-progress {id, line}`; pipe progress from `runSubagent` through the `task` tool in `agent-core/src/tools/task.ts` → `apps/desktop/src/main/agent.ts` → renderer. Render a rich SubagentCard per concurrent task call (spinner, current activity, collapsed report), parallel calls as sibling cards.
- **Turn-end stop-reason notice** (dsh turn-end-stop-reason): subtle system row for max-steps/aborted/compaction; final assistant text always flushed before fold (fixes result-card completeness).
- **FileCard**: restyle to dsh diff-card (single path header, +/- stats).
